# Security Policy

## Supported versions

| Version | Supported |
| :--- | :---: |
| 1.1.x | Yes |
| 1.0.x | Security fixes only when practical |
| Older versions | No |

Use the newest `1.1.x` release before reporting a problem.

## Reporting a vulnerability

Do not open a public issue for an undisclosed vulnerability. Use GitHub's private vulnerability reporting flow for this repository:

https://github.com/alexandroit/stackline-multiselect/security/advisories/new

Include the affected version, a minimal reproduction, the expected impact, and any known mitigations. Reports are reviewed before public disclosure or release notes are prepared.
